# Concursos IA - Guia Completo

## Visão Geral

O Concursos IA é um aplicativo multiplataforma (Android/iOS/Web) com modelo "freemium" desenvolvido para auxiliar candidatos na preparação para concursos públicos no Brasil. Combinando tecnologias de inteligência artificial com metodologias eficientes de estudo, o aplicativo oferece uma experiência personalizada para maximizar o aproveitamento do tempo de estudo e aumentar as chances de aprovação.

## Principais Funcionalidades

### 1. Análise Inteligente de Editais

O aplicativo utiliza tecnologia avançada de IA para analisar editais de concursos e extrair automaticamente:

- **Informações Gerais**: Órgão, banca organizadora, datas importantes, taxas de inscrição
- **Cargos e Requisitos**: Detalhes sobre os cargos disponíveis e seus requisitos
- **Conteúdo Programático**: Matérias e assuntos exigidos para cada cargo
- **Critérios de Desempate**: Fatores considerados em caso de empate
- **Informações sobre Cotas**: Vagas reservadas para pessoas pretas/pardas, PCD, indígenas

O processo de análise é visualmente acompanhado por animações dinâmicas que alternam entre diferentes estilos (Matrix, Viagem Espacial, Redes Neurais e Processamento de Dados).

### 2. Planos de Estudo Personalizados

Com base na análise do edital, o aplicativo cria planos de estudo personalizados considerando:

- **Tempo Disponível**: Adaptado à data da prova e disponibilidade do candidato
- **Priorização Inteligente**: Baseada no peso das matérias no edital
- **Número de Questões**: Foco nas matérias com maior incidência de questões
- **Critérios de Desempate**: Atenção especial às matérias usadas como critério de desempate
- **Nível de Proficiência**: Adaptação conforme o conhecimento prévio do candidato

### 3. Ferramentas de Estudo com IA

O aplicativo oferece ferramentas poderosas para otimizar o aprendizado:

- **Flashcards**: Criação automática de cartões de memorização para revisão espaçada
- **Resumos**: Geração de resumos concisos dos principais tópicos
- **Mapas Mentais**: Visualização hierárquica de conceitos no formato markmap.js.org
- **Questões**: Geração de questões para praticar os conhecimentos

Todas essas ferramentas são alimentadas por IA e podem ser geradas a partir de documentos enviados pelo usuário (PDF, DOCX, TXT, HTML).

### 4. Sessões de Estudo Estruturadas

Para maximizar a produtividade, o aplicativo oferece:

- **Cronômetros Configuráveis**: Timers progressivos e regressivos, incluindo técnica Pomodoro
- **Rastreamento de Progresso**: Registro automático do tempo estudado e assuntos abordados
- **Marcação de Progresso**: Sistema de checkboxes coloridos (verde, amarelo, laranja, vermelho) para acompanhar o nível de revisão de cada assunto

### 5. Gamificação e Motivação

Para manter o engajamento e a motivação, o aplicativo implementa:

- **Moedas Virtuais**: Ganhas por tempo de estudo, conclusão de metas e manutenção de sequências
- **Mercado de Recompensas**: Troca de moedas por benefícios e recompensas personalizadas
- **Sequências de Estudo**: Acompanhamento de "streaks" de dias consecutivos de estudo
- **Metas e Desafios**: Objetivos diários, semanais e mensais para manter o foco

## Interface e Design

O aplicativo apresenta uma interface moderna e elegante com:

- **Tema Escuro**: Fundo escuro com gradientes vibrantes (azul-ciano e rosa-roxo)
- **Elementos Arredondados**: Botões e cards com cantos arredondados para uma aparência suave
- **Efeitos de Brilho**: Botões com aparência de LED e efeitos sutis de brilho
- **Esquema de Cores**: Uso de cores específicas para cada ferramenta (rosa para Flashcards, ciano para Resumos, verde para Questões, âmbar para Mapas Mentais)
- **Alta Legibilidade**: Contraste adequado entre texto e fundo para facilitar a leitura

## Organização do Conteúdo

O conteúdo programático é organizado de forma hierárquica:

- **Grupos**: Categorias principais (ex: Conhecimentos Básicos, Conhecimentos Específicos)
- **Cargos**: Cargos específicos do concurso
- **Categorias**: Subdivisões dos grupos
- **Matérias**: Disciplinas específicas
- **Assuntos**: Tópicos específicos dentro de cada matéria

Esta estrutura facilita a navegação e o acompanhamento do progresso em diferentes níveis de granularidade.

## Experiência Ideal de Uso

### 1. Primeiros Passos

1. **Cadastro e Configuração**: Criar uma conta e configurar a chave de API (Gemini)
2. **Análise do Edital**: Enviar o PDF do edital do concurso desejado
3. **Seleção de Cargo**: Escolher o cargo pretendido
4. **Configuração do Plano**: Informar disponibilidade de tempo e nível de conhecimento

### 2. Ciclo de Estudos Diário

1. **Consulta do Dashboard**: Verificar as sessões programadas para o dia
2. **Sessão de Estudo**: Iniciar uma sessão focada em uma matéria específica
3. **Utilização das Ferramentas**: Usar flashcards, resumos, mapas mentais ou questões conforme necessário
4. **Marcação de Progresso**: Atualizar o status de cada assunto estudado
5. **Revisão do Progresso**: Verificar estatísticas e conquistas no final do dia

### 3. Acompanhamento Semanal

1. **Análise do Calendário**: Verificar o cumprimento do plano na semana
2. **Ajuste de Prioridades**: Reforçar matérias com menor progresso
3. **Resgate de Recompensas**: Utilizar moedas acumuladas no Mercado de Aprovação

### 4. Revisão Mensal

1. **Análise de Estatísticas**: Verificar o tempo dedicado a cada matéria
2. **Teste de Conhecimentos**: Realizar simulados para avaliar o aprendizado
3. **Ajuste do Plano**: Refinar o plano de estudos conforme necessário

## Dicas para Aproveitar ao Máximo

1. **Consistência**: Mantenha uma rotina diária de estudos, mesmo que por períodos curtos
2. **Revisão Espaçada**: Utilize o sistema de marcação colorida para implementar revisões espaçadas
3. **Personalização**: Ajuste as configurações do aplicativo para atender às suas necessidades específicas
4. **Gamificação**: Aproveite o sistema de recompensas para manter a motivação
5. **Ferramentas Complementares**: Alterne entre as diferentes ferramentas de estudo para reforçar o aprendizado

## Requisitos Técnicos

- **Plataformas**: Android, iOS, Web
- **Conexão com Internet**: Necessária para análise de editais e geração de conteúdo com IA
- **Armazenamento**: Espaço suficiente para armazenar documentos e conteúdo gerado
- **Chave de API**: Própria chave de API do Gemini para utilizar recursos de IA

## Modelo de Acesso

- **Versão Gratuita**: Acesso a funcionalidades básicas com anúncios
- **Versão Premium**: Acesso completo sem anúncios e com recursos avançados
