# Utils

Esta categoria contém utilitários e helpers usados em todo o aplicativo:

## Logger

Sistema de logging para registro de eventos, erros e informações de depuração:

- Níveis de log configuráveis
- Registro em arquivo
- Formatação de logs
- Suporte a tags para categorização

## Formatters

Utilitários para formatação de dados:

- Formatação de data e hora
- Formatação de valores monetários
- Formatação de números
- Formatação de texto

## Validators

Utilitários para validação de dados:

- Validação de e-mail
- Validação de senha
- Validação de CPF
- Validação de URL

## Constants

Constantes usadas em todo o aplicativo:

- Cores
- Tamanhos
- Strings
- Configurações

## Extensions

Extensões para tipos nativos e classes do Flutter:

- Extensões para String
- Extensões para DateTime
- Extensões para List
- Extensões para Widget

## Helpers

Funções auxiliares para tarefas comuns:

- Manipulação de arquivos
- Manipulação de imagens
- Manipulação de texto
- Manipulação de dados
