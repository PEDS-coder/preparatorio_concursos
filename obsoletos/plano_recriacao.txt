# PLANO DE RECRIAÇÃO DA APLICAÇÃO CONCURSOS IA

## OBJETIVO
Recriar a aplicação Concursos IA em uma nova pasta (C:\Users\plini\Desktop\concursos_ia\concurso_ia) para evitar problemas com o OneDrive e garantir o funcionamento correto.

## FUNCIONALIDADES DA APLICAÇÃO ORIGINAL

### Fluxo Principal
1. Tela de Splash
2. Tela de Boas-vindas
3. Página de login
4. Configuração da API (Google Gemini ou OpenAI)
5. Upload de arquivos do edital
6. Seleção de cargo
7. Perguntas sobre horários disponíveis e proficiência nas matérias
8. Apresentação do plano de estudos personalizado
9. Dashboard principal

### Funcionalidades Principais
- **Autenticação de Usuário**: Login, registro e recuperação de senha
- **Integração com IA**: Processamento de editais e geração de planos de estudo personalizados
- **Gestão de Editais**: Upload, análise e armazenamento de editais de concursos
- **Plano de Estudos**: Criação e visualização de planos personalizados
- **Sessões de Estudo**: Agendamento e acompanhamento de sessões
- **Gamificação**: Sistema de recompensas, troféus e mercado virtual
- **Estatísticas e Progresso**: Acompanhamento do desempenho do usuário

### Design e UI
- Tema escuro e claro
- Gradientes e elementos visuais modernos
- Cards informativos
- Gráficos e visualizações de dados
- Calendário de estudos

### Integrações
- Google Gemini API
- OpenAI API
- Armazenamento local para dados do usuário
- Armazenamento seguro para chaves de API

## REQUISITOS PARA RECRIAÇÃO

### Estrutura de Pastas
- Arquitetura limpa com separação de camadas (features, core, etc.)
- Organização por funcionalidades

### Dependências
- Flutter SDK
- Provider para gerenciamento de estado
- GetIt para injeção de dependências
- HTTP para chamadas de API
- SharedPreferences para armazenamento local
- Flutter Secure Storage para armazenamento seguro
- Intl para internacionalização
- Table Calendar para o calendário de estudos

### Serviços
- Serviço de Autenticação
- Serviço de IA
- Serviço de Edital
- Serviço de Plano de Estudo
- Serviço de Sessão de Estudo
- Serviço de Gamificação
- Serviço de Estatísticas
