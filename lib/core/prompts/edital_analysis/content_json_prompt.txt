**Tarefa:** Extrair o conteúdo programático completo (conhecimentos básicos e específicos) aplicável a um cargo específico de um edital de concurso público fornecido, identificar o peso de cada matéria, critérios de desempate e número de questões, e apresentar o resultado em formato JSON.

**Contexto:** Editais de concursos públicos frequentemente estruturam o conteúdo programático de maneiras variadas. Conhecimentos básicos podem ser comuns a todos os cargos, aplicáveis apenas a alguns níveis ou áreas, ou ter exceções. Conhecimentos específicos são geralmente vinculados a um cargo ou área. Sua tarefa é analisar o texto do edital, identificar o cargo alvo e determinar *precisamente* quais seções de conhecimentos básicos e específicos se aplicam a ele, listando todas as matérias/tópicos correspondentes. Além disso, você deve identificar se há matérias com peso maior na pontuação final, matérias que são critérios de desempate, e o número de questões de cada matéria, quando essas informações estiverem disponíveis no edital.

**Cargo Alvo:**
[CARGO_ALVO]

**Instruções:**
1. Analise o edital completo para entender a estrutura do conteúdo programático.
2. Identifique todas as matérias de conhecimentos básicos que se aplicam ao cargo alvo.
3. Identifique todas as matérias de conhecimentos específicos que se aplicam ao cargo alvo.
4. Para cada matéria, liste todos os tópicos detalhados conforme apresentados no edital.
5. Identifique se há matérias com peso maior na pontuação final (que valem mais pontos).
6. Identifique se há matérias que são utilizadas como critério de desempate.
7. Identifique o número de questões de cada matéria, quando essa informação estiver disponível.
8. Estruture sua resposta EXCLUSIVAMENTE em formato JSON, seguindo o modelo abaixo.
9. Não omita nenhum tópico ou matéria aplicável ao cargo.
10. Não inclua matérias ou tópicos que não se aplicam ao cargo alvo.
11. Preserve o texto exato dos tópicos conforme apresentado no edital.
12. Não adicione comentários, explicações ou texto fora do JSON.

**Formato da Resposta (JSON):**

```json
{
  "cargo": "Nome Exato do Cargo Desejado",
  "conteudo_programatico": [
    {
      "nome": "Nome da Disciplina/Matéria 1",

      "peso_maior": true,
      "criterio_desempate": false,
      "numero_questoes": 10,
      "topicos": [
        "Tópico 1.1",
        "Tópico 1.2",
        "..."
      ]
    },
    {
      "nome": "Nome da Disciplina/Matéria 2",
      "tipo": "especifico",
      "peso_maior": false,
      "criterio_desempate": true,
      "numero_questoes": 5,
      "topicos": [
        "Tópico 2.1",
        "Tópico 2.2",
        "..."
      ]
    }
  ]
}
```

**IMPORTANTE:**
- Sua resposta deve conter APENAS o JSON, sem texto introdutório ou explicativo.
- Certifique-se de que o JSON seja válido e bem formatado.
- Use "comum" para conhecimentos básicos e "especifico" para conhecimentos específicos.
- Para "peso_maior", use true se a matéria tiver peso maior na pontuação final, false caso contrário.
- Para "criterio_desempate", use true se a matéria for utilizada como critério de desempate, false caso contrário.
- Para "numero_questoes", indique o número de questões da matéria. Se não for possível determinar, use null.
- Não use abreviações para os nomes das disciplinas, a menos que estejam abreviadas no edital.
- Inclua TODOS os tópicos de cada disciplina, mesmo que sejam muitos.
- Não adicione tópicos que não estejam no edital.
- Não omita nenhuma disciplina ou tópico relevante para o cargo.
- Não inclua delimitadores de código (```json) na sua resposta final.
- IMPORTANTE: Não inclua "Conhecimentos Específicos" ou "Conhecimentos Básicos" como nomes de disciplinas. Estes são apenas cabeçalhos de seções, não disciplinas em si.
