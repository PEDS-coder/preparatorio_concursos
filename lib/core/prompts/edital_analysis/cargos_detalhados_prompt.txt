**Tarefa:** Extrair APENAS informações detalhadas sobre os cargos disponíveis em um edital de concurso público e apresentar o resultado em formato JSON.

**Contexto:** Você está analisando um edital de concurso público. Sua tarefa é extrair APENAS as informações essenciais sobre os cargos disponíveis, incluindo detalhes específicos sobre requisitos, datas e horários das provas.

**Instruções Detalhadas:**

1. **Informações dos Cargos:**
   - Liste todos os cargos disponíveis no concurso
   - Para cada cargo, extraia:
     - Nome exato e completo do cargo (como aparece no edital, incluindo área/especialidade quando aplicável)
     - Número de vagas (se for apenas cadastro de reserva, indique explicitamente)
     - Remuneração/salário (valor numérico sem símbolos, ex: 5000.00)
     - Requisitos/escolaridade mínima (seja específico sobre o nível: superior, médio, etc.)
     - Requisitos específicos (formação, registro profissional, experiência, etc.)
     - Data e horário da prova para este cargo específico (se disponível)
     - Área/especialidade (se aplicável)

2. **Formate a Saída em JSON:**
   Organize as informações extraídas no seguinte formato JSON:

```json
{
  "total_cargos": 3,
  "cargos": [
    {
      "nome": "Analista em Tecnologia da Informação",
      "vagas": 10,
      "cadastro_reserva": false,
      "salario": 5000.00,
      "escolaridade": "Nível Superior",
      "requisitos": "Graduação em Ciência da Computação, Sistemas de Informação ou áreas afins. Registro no conselho profissional.",
      "data_prova": "2023-10-15",
      "horario_prova": "13:00",
      "area": "Tecnologia da Informação"
    },
    {
      "nome": "Analista em Contabilidade",
      "vagas": 0,
      "cadastro_reserva": true,
      "salario": 3500.00,
      "escolaridade": "Nível Superior",
      "requisitos": "Graduação em Ciências Contábeis. Registro no CRC.",
      "data_prova": "2023-10-15",
      "horario_prova": "08:00",
      "area": "Contabilidade"
    },
    {
      "nome": "Técnico Judiciário - Área Administrativa",
      "vagas": 5,
      "cadastro_reserva": false,
      "salario": 2500.00,
      "escolaridade": "Nível Médio",
      "requisitos": "Ensino Médio completo",
      "data_prova": "2023-10-22",
      "horario_prova": "13:00",
      "area": "Administrativa"
    }
  ]
}
```

**Instruções Importantes:**
1. Extraia APENAS as informações dos cargos, não inclua outras informações do concurso.
2. Forneça sua resposta EXCLUSIVAMENTE em formato JSON válido.
3. Não inclua texto introdutório, explicações ou comentários fora do JSON.
4. Certifique-se de incluir TODOS os cargos mencionados no edital.
5. MUITO IMPORTANTE: Extraia o nome COMPLETO e ESPECÍFICO de cada cargo, incluindo a área/especialidade. NÃO use nomes genéricos como "Analista" ou "Técnico" sem especificar a área/especialidade.
6. Se houver vários cargos com o mesmo título base (ex: "Analista") mas com diferentes especialidades, liste-os como cargos separados com seus nomes completos (ex: "Analista em Tecnologia da Informação", "Analista em Contabilidade").
7. Se um cargo tiver apenas cadastro de reserva (sem vagas imediatas), defina "vagas" como 0 e "cadastro_reserva" como true.
8. Se não conseguir determinar alguma informação, use valores vazios ("") ou nulos (null) conforme apropriado.
9. É EXTREMAMENTE IMPORTANTE que você inclua a lista de cargos no campo "cargos" do JSON, e não em outros campos como "cargos_disponiveis" ou similares.
10. Certifique-se de que a lista de cargos não esteja vazia. Se não conseguir identificar cargos específicos, inclua pelo menos um cargo genérico com nome "Cargo Genérico".
11. Verifique se o JSON final é válido e se a lista de cargos está presente e não vazia.
12. Sempre inclua o campo "cargos" no JSON, mesmo que não encontre cargos específicos.
13. IMPORTANTE: Extraia as datas e horários específicos das provas para cada cargo, pois isso será usado para verificar conflitos de horários.
