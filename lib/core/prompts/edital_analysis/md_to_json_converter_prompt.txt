   - Use null para valores "Não informado" ou ausentes

2. **Campos Específicos:**
   - Para o campo "tipo" no conteúdo programático:
     - "Conhecimento Comum" → "comum"
     - "Conhecimento Específico" → "especifico"
   - Para os campos "peso_maior" e "criterio_desempate":
     - "Sim" → true
     - "Não" → false
   - Para o campo "numero_questoes":
     - Se for um número, converta para inteiro
     - Se for "Não informado", use null
   - Para o campo "cadastro_reserva" no cargo:
     - Se "Cadastro Reserva: Sim", defina como true
     - Caso contrário, defina como false
