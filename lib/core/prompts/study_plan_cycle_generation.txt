Para criar o ciclo de estudos, siga estas regras de priorização:

**Sistema de Pontuação para Priorização de Matérias:**
1. Matérias com peso maior no edital: +10 pontos
2. Matérias com peso menor no edital: +1 ponto
3. Matérias com mais questões na prova: +8 pontos
4. Matérias com menos questões na prova: +1 ponto
5. Matérias que são critérios de desempate: +5 pontos
6. Matérias que não são critérios de desempate: +0 pontos
7. Proficiência do estudante:
   - Iniciante: +10 pontos
   - Básico: +8 pontos
   - Intermediário: +5 pontos
   - Avançado: +2 pontos
   - Especialista: +1 ponto

**Eficácia das Ferramentas de Estudo (escala 1-10):**
1. Plataformas de Questões: 10
2. Flashcards: 9
3. PDFs/Livros: 8
4. Videoaulas: 7
5. Resumos: 6
6. Audioaulas: 5

**Nota sobre a ferramenta "Lei seca":**
A ferramenta "Lei seca" (leitura direta da legislação) deve ser utilizada APENAS para matérias jurídicas como Direito Constitucional, Direito Administrativo, Direito Civil, Direito Penal, Direito Processual, Legislação específica, etc. Não utilize esta ferramenta para matérias não-jurídicas como Matemática, Português, Raciocínio Lógico, Informática, etc.

**Diretrizes para o Ciclo de Estudos:**
1. Crie um único ciclo com dias suficientes para que o usuário veja ao menos uma vez cada matéria e use ao menos uma vez cada ferramenta de estudo disponível.
2. Aloque mais tempo para matérias com maior pontuação de prioridade.
3. Alterne entre matérias teóricas e práticas para evitar fadiga mental.
4. Alterne entre ferramentas de estudo, priorizando as mais eficazes.
5. Cada bloco de estudo deve ter entre 60 e 150 minutos.
6. Distribua as matérias de forma que disciplinas similares não fiquem em sequência.
7. Alterne entre disciplinas que usam diferentes hemisférios cerebrais (ex: alternar entre matérias de exatas e humanas).
8. Inclua pequenos intervalos entre os blocos (não é necessário especificar no JSON).
