# Plano de Implementação

## Problemas Identificados
1. A segunda chamada à API não está sendo realizada antes da navegação para a tela de questionário
2. As matérias do cargo não estão sendo apresentadas na tela de questionário
3. A navegação não está intuitiva, com passos desnecessários

## Soluções Planejadas
1. Corrigir a extração do conteúdo programático
   - Modificar o método `_continuarParaPlanoEstudo()` para garantir que a chamada à API seja realizada
   - Adicionar logs para verificar o funcionamento da API
   - Garantir que o conteúdo programático seja armazenado corretamente

2. Corrigir a exibição das matérias na tela de questionário
   - Modificar a tela `PlanoQuestionarioScreen` para exibir as matérias
   - Garantir que as matérias sejam passadas corretamente

3. Melhorar a navegação
   - Simplificar o fluxo de navegação
   - Adicionar o botão "Criar Plano" diretamente na tela de análise do edital
